set threads

set threads N

Sets the number of CPU threads used by accelerated in-memory grid calculations. N must be a positive integer. The default is 4.

q threads reports the current setting and whether OpenMP was enabled when GrADS was built.

Other ways to select the count

grads -j N selects the count at process startup, and the GA_NUM_THREADS environment variable changes the startup default. The -j option takes precedence over the environment variable.

Usage notes

Use set threads 1 to run calculations serially. Small grids may remain serial even when a larger value is selected because thread startup would cost more than the calculation.
